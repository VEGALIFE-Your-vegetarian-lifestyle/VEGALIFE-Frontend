Bản vẽ này ăn khớp schema nào

  • Rail trái ← profile.username, email, bmi; số cạnh mục nav ← posts.total, recipes.pending.
  • Dải tổng 4 ô ← posts.published, posts.totalViews, recipes.total/pending, mealPlan.current.mealCount.
  • 3 việc đang chờ ← attention[] (kind, title, occurredAt, refId).
  • Bài viết / Công thức ← posts.latest[], recipes.latest[] + đếm theo status ở dòng footer.
  • Thực đơn ← mealPlan.current (status, startDate/endDate, mealCount). 21 ô = 7 × 3 bữa.
  • Hồ sơ ← profile.bmi, bmiCategory, healthGoal, updatedAt; chip đếm từ 4 mảng dietary.

Rail dùng --dark + --green-bright, ô tuần dùng --green-subtle — toàn token có sẵn trong @theme. Không gradient. Không biểu đồ thời gian / streak / lượt lưu / bình luận: API chưa trả.
